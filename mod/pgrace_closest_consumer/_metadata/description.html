See where your cargo can go

Click any industry or warehouse, and Closest Consumer adds a Nearest consumers card to its window. For each cargo the building sends out, it lists the three closest industries and towns that use that cargo, with the distance to each.

Features

  • Nearest consumers per cargo: the three closest industries or towns that accept each output, sorted by distance.
  • Show a single flow: the arrow button on a row draws one cargo-flow arrow on the map, from the building to that consumer, and moves the camera so both ends are in view. The arrow is animated if you already deliver cargo there, and faint if you don't yet.
  • Warehouses too: for a warehouse, the card lists consumers for the cargo it stores. An empty warehouse uses the cargo types its slots accept.
  • Quick navigation: the locate button moves the camera to a consumer, and clicking its name opens that consumer's window.

How to use

  1. Open the window of an industry or a warehouse.
  2. Find the Nearest consumers card below the stocks.
  3. Click the arrow button on a row to show that flow on the map. Click it again, or close the window, to go back to the normal view.

Good to know

  • Distances are measured in a straight line, not along roads or tracks.
  • Only industries and towns that actually use the cargo are listed. Warehouses are never listed as consumers.
  • The list is worked out when the window opens. Reopen the window to refresh it.
  • While a flow arrow is shown, it replaces the window's usual map overlay (catchment area and the arrows to all consumers).
  • This is a cosmetic mod. It doesn't change the simulation, so achievements stay available, and you can add it to or remove it from existing saves.
